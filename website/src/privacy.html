灵言 TypeFree 输入法隐私政策与用户协议

生效与更新日期：2026 年 11 月 23 日 ｜ 开发者与运营主体：TypeFree 开发团队（联系邮箱：support@xuezhao.space）

一、数据处理基本原则

  • 无中心化文字收集服务器：灵言 TypeFree 不设后台云端服务器收集您的日常键盘敲击记录、候选词、个人词典、剪贴板历史或识别历史。上述数据均加密或隔离存储于您当前设备的本地存储空间中。
  • 密码框与无痕自动避让：遇到系统密码输入框、金融支付框或手动开启无痕模式时，自动跳过词频自学习、剪贴板记录、输入统计与上下文感知。
  • 纯离线与自有接口直连（BYOK）：若您启用本机离线模型，语音与文本处理 100% 在本机完成，零网络传输；若您自行配置第三方大模型服务商 API Key，音频或文本将由您的设备通过 HTTPS/WSS 直接发往您所配置的对应服务商官方接口，不经过开发者服务器中转。

二、按需权限与系统服务调用说明

  • 网络访问权限（INTERNET / ACCESS_NETWORK_STATE）：仅用于按您的主动操作下载开源离线模型包、直连您自行填写的 API 服务商接口，或在激活 Pro 授权码时完成一次性设备绑定校验。开启「纯离线零出网」模式后将阻断业务联网请求。
  • 麦克风录音权限（RECORD_AUDIO / FOREGROUND_SERVICE_MICROPHONE）：默认不申请；仅在您主动点击键盘语音按钮或启用悬浮语音胶囊录音时按需采集音频，松手或取消后立即停止采集。
  • 无障碍服务（AccessibilityService，可选进阶权限）：默认关闭，纯打字、基础语音输入、帮我写与问 AI 均无需开启。仅在您主动开启以下两项可选功能之一时使用：
    1. 「✦ Jev 军师读取聊天上文」：仅在您主动点击「✦ 军师」按钮的瞬间，按需读取当前活动聊天窗口可见文本（若您额外开启截图理解，将按需截取当前聊天区域），经本机端侧脱敏引擎（LocalPiiRedactor，自动替换手机号、身份证号、银行卡号、邮箱等敏感信息）处理后发送至您配置的模型生成回复建议，退出面板即刻从内存销毁，不落盘保存；
    2. 「跨应用悬浮语音胶囊」：识别输入框焦点并将语音转写结果直接填入光标处。
  • 悬浮窗权限（SYSTEM_ALERT_WINDOW，可选）：默认关闭；仅在您主动开启「无需切换键盘的悬浮语音胶囊」时用于在输入框旁展示声波悬浮按钮。
  • 已安装应用查询（queries MAIN/LAUNCHER）：仅在您已同意本隐私政策且进入「应用自动匹配规则」设置页时，在设备本地读取可启动应用的名称与包名，以便您为不同宿主应用（如聊天软件、邮件客户端）绑定不同润色语气，应用列表数据绝不上传。

三、数据管理与注销清除

您可随时在应用内「通用」或对应功能页面一键清空识别历史、剪贴板记录、端侧纯数字表达统计及 Jev 本地关系记忆库（支持轮换 Android Keystore 硬件盐值），或通过系统应用管理清除全部本地应用数据。

四、Pro 永久授权与用户协议条款

  • TypeFree 基础打字、自带 API（BYOK）与轻巧离线语音/净写永久免费开放。
  • 购买或通过官方活动兑换 TypeFree Pro 永久授权后，可解锁当前及未来所有本机客户端与自带 API 高阶功能更新（单个激活码最多支持绑定 3 台个人自用设备，严禁公开传播或倒卖授权码；Google Play 渠道购买遵循 Google Play 结算与退款规则）。
  • 未来若推出消耗官方服务器算力的「免 Key 云端流量包」，将作为独立可选增值服务按需选购，不影响已有离线与自带 API 功能。
