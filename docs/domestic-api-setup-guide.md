# TypeFree 国内直连 API 配置指南（豆包 / 硅基流动 / 通义千问 & DeepSeek 混搭实战）

本指南面向国内网络环境用户，重点介绍如何使用 **火山引擎（豆包）**、**硅基流动（SiliconFlow）**、**阿里云百炼（通义千问）** 独立配置使用，以及如何将这三家的 **流式 / 高速语音识别（一阶段）** 与 **DeepSeek 官方 API（二阶段与军师大脑）** 黄金混搭。

---

## 一、先看懂原理：为什么是一阶段「听音」+ 二阶段「大脑」？

在 TypeFree 主应用的 **「API 配置 → 2. 工作流与模型自由混搭」** 中，选择 **`⚡ 实时流式 / 双阶段`** 模式时，整条 AI 链路被拆为前后两段：

```text
🎙️ 你说话 (.pcm / .wav 音频)
   │
   ▼  【一阶段：👂 听音转写引擎 (STT)】
   │   • 实时流式 WebSocket：阿里云百炼 / 火山引擎豆包（边说边上屏）
   │   • HTTP 整包上传：硅基流动 SenseVoiceSmall（POST /v1/audio/transcriptions）
   │
   ▼  识别出原始文本
   │
   ▼  【二阶段：🧠 语义润色 & ✍️ 帮写 & 🔍 问AI & ✦ Jev 军师 (LLM)】
       • 支持所有纯文本/多模态大模型：DeepSeek / 豆包 / 通义千问 / 硅基流动
```

### ⚠️ 重要结论：为什么 DeepSeek 只能做二阶段（且不能填进一阶段非流式）？
1. **一阶段的「OpenAI 兼容 HTTP 整包（非流式）」不是聊天框**，它会在你松手后把 `.wav` 录音文件上传到 `/v1/audio/transcriptions` 语音识别端点；
2. **DeepSeek 官方（`https://api.deepseek.com/v1`）只提供纯文本对话接口（`/v1/chat/completions`）**，没有语音识别端点，模型也不接收音频数据，因此**不能**填到一阶段听音里；
3. 但**所有与文字、思考、回复相关的重头戏**——语音口述润色、`✍️ 帮写`、`🔍 问AI` 以及 **`✦ Jev 军师`**——全部跑在二阶段，**DeepSeek 都能直接胜任**！

## 三、方案一：单平台独立打通（豆包 / 硅基流动 / 通义千问）

如果你只想注册一个平台、用最少步骤快速跑通，按对应小节操作即可：

### 1. 硅基流动（SiliconFlow）—— 免费高速听音，一把 Key 起飞
1. 在 [硅基流动控制台](https://cloud.siliconflow.cn/) 创建 API Key（`sk-...`）。
2. 打开 TypeFree **「API 配置 → 1. 服务商凭证保险箱」**，点选 **「硅基流动」** 瓷砖。
3. 粘贴 `sk-...` Key，点击下方 **「🚀 一键设为当前主力方案」**：
   - **一阶段 STT**：自动配好 `OpenAI 兼容 HTTP 整包` + `FunAudioLLM/SenseVoiceSmall`（免费且中文/中英混读准确度高）。
   - **二阶段 LLM**：自动配好 `Qwen/Qwen2.5-7B-Instruct`。
4. **进阶优化军师效果**：
   - 在下方展开 **「✦ Jev 军师专用模型（高情商/多模态独立路由）」** 开关；
   - 选择 **「硅基流动」**，模型选 **`deepseek-ai/DeepSeek-V3`**（纯文本高质量）或 **`Qwen/Qwen2.5-VL-72B-Instruct`**（若需要军师看懂聊天截图里的表情包/图片）；
   - 思考模式保持 **「自动 (AUTO)」** 即可，系统会在军师下自动开启有界思考与 SSE 流式逐卡上屏。

---

### 2. 阿里云百炼 / 通义千问 —— 单个 `sk-` Key 原生 WebSocket 实时流式
阿里云百炼的一大优势是 **只需一个 `sk-...` Key，即可同时驱动 WebSocket 实时边说边写与 Qwen 大模型**，无需区分 AppID。

1. 登录 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，确认已开通模型服务并创建一个 `API Key`（`sk-...`）。
2. 在 TypeFree **「1. 服务商凭证保险箱」** 点选 **「阿里云百炼」**，填入 `sk-...` Key。
3. 点击 **「🚀 一键设为当前主力方案」**：
   - **一阶段 STT**：自动启用 **`阿里云百炼 WebSocket 实时流式`**，默认模型 `paraformer-realtime-v2`（也可以在下拉预设换 `fun-asr-realtime` 或多语 `gummy-realtime-v1`）。
   - **二阶段 LLM**：自动使用 `qwen-turbo-latest`（极速关思考）。
4. **进阶优化军师效果**：
   - 打开 **「✦ Jev 军师专用模型」** → 选 **「阿里云百炼」**；
   - 推荐模型：**`qwen-plus-latest`**（速度与情商均衡）或 **`qwen-max-latest`**；如果常发图给军师看，选 **`qwen-vl-max-latest`**。

---

### 3. 火山引擎 / 豆包 —— 豆包同源流式 SeedASR 2.0 + Seed 2.1
火山引擎需要留意：**「火山方舟（文本大模型）」和「豆包语音（流式识别）」在控制台属于两个入口**，App 内已为豆包预留了分开填写的输入框：

1. **获取火山语音（👂 听音，SeedASR 2.0 流式）凭证**：
   - 前往 [火山引擎豆包语音控制台](https://console.volcengine.com/speech/app)，创建应用并开通 **「流式语音识别大模型」**（对应 Resource ID 默认已填好 `volc.seedasr.sauc.duration`；若你开通的是旧版 1.0 `volc.bigasr.sauc.duration`，可在「3. 高级连接覆盖与 1-Token 测速」里修改 `火山语音 Resource ID`）。
   - 若控制台给出的是 **`App ID` + `Access Token`**：分别填入第 2 栏 **`火山语音豆包流式 Access Token`** 与第 3 栏 **`火山语音 AppID`**。
   - 若控制台给出的是**新版单 `X-Api-Key`**：只需填入第 2 栏 `Access Token`，第 3 栏 `AppID` 留空即可。
2. **获取火山方舟（🧠 润色与军师）凭证**：
   - 前往 [火山方舟控制台](https://console.volcengine.com/ark)，创建 API Key 填入第 1 栏 **`火山方舟 API Key（豆包 LLM 润色 / 单 Key）`**，并在控制台开通推理模型（`doubao-seed-2-1-lite-260915`、`doubao-seed-2-1-pro-260915` 等；如果你用自定义推理接入点 `ep-xxx`，也可在「Model」框手填接入点 ID）。
3. 点击 **「🚀 一键设为当前主力方案」**：
   - **一阶段 STT**：自动启用 **`火山豆包 WebSocket 实时流式`**（`bigmodel`），按住说话边说边上屏；
   - **二阶段 LLM**：默认使用 `doubao-seed-2-1-lite-260915` 关思考极速润色。
4. **进阶优化军师效果**：
   - 打开 **「✦ Jev 军师专用模型」** → 选 **「火山引擎豆包」** → 模型选 **`doubao-seed-2-1-pro-260915`**，思考模式保持 **「自动 (AUTO)」**。该模型同时支持 **有界思考 + 原生聊天截图识别 + SSE 流式**，综合体验极稳。

## 四、方案二：前三家流式/高速听音 + DeepSeek 官方 API（黄金混搭重点）

如果你想把 **豆包 / 通义千问的实时流式听音（或硅基流动免费听音）** 和 **DeepSeek 官方 API** 组合在一起，推荐按如下顺序配置：

### 🌟 黄金配置两步法（通用）
1. **第 1 步（先定耳朵）**：在「1. 服务商凭证保险箱」选择 **阿里云百炼 / 火山引擎豆包 / 硅基流动** 之一，填好其语音 Key 并点击一次 **「🚀 一键设为当前主力方案」**，让它坐镇一阶段听音；
2. **第 2 步（再换 DeepSeek 大脑）**：在保险箱点选 **「DeepSeek」**，填入官方 API Key（`sk-...`），点击 **「🧠 一键设为文本大脑（二阶段润色 & 军师）」**！

> ✅ **新版智能机制**：点完 DeepSeek 按钮后，系统会保留你刚才配好的百炼/豆包/硅基一阶段听音通道（如果你先填了 DeepSeek 后补填听音 Key，在「2. 工作流与模型自由混搭 -> 👂 听音转写引擎」里点一下对应服务商即可，或者点 DeepSeek 按钮时会自动从密码本检索并回填已有 STT）。

---

### 三套混搭核对清单

#### 组合 B1：阿里云百炼（千问流式听音）+ DeepSeek 大脑
- **第 1 步**：点「阿里云百炼」填 `sk-...` → 点「🚀 一键设为当前主力方案」。
- **第 2 步**：点「DeepSeek」填 `sk-...` → 点「🧠 一键设为文本大脑（二阶段润色 & 军师）」。
- **核对「2. 工作流与模型自由混搭」**：
  - `👂 听音转写引擎`：高亮 **阿里云百炼**，模型 `paraformer-realtime-v2`（实时流式边说边写）。
  - `🧠 二阶段语义润色 & 写作快译模型`：高亮 **DeepSeek**，模型 `deepseek-chat`。

#### 组合 B2：火山豆包（SeedASR 2.0 流式听音）+ DeepSeek 大脑（✨ 极力推荐）
- **情况一（豆包语音 + 方舟都开过）**：先在「火山引擎豆包」填好语音 `Access Token` / `AppID`（与方舟 Key，如只当耳朵用方舟 Key 可空或只填语音 Token）→ 点「🚀 一键设为当前主力方案」→ 再到「DeepSeek」填 Key 点「🧠 一键设为文本大脑」。
- **情况二（我只开通了豆包语音，完全不想开火山方舟）**：
  1. 在「火山引擎豆包」瓷砖里**只填第 2 栏 `Access Token` 和第 3 栏 `AppID`**（第 1 栏方舟 Key 留空）；
  2. 在「DeepSeek」瓷砖里填好 `sk-...` → 点击「🧠 一键设为文本大脑」；
  3. 到下方 **「2. 工作流与模型自由混搭 -> 👂 听音转写引擎」** 直接点选 **「火山引擎豆包」**，确保听音切换为 `bigmodel`（`火山豆包 WebSocket 实时流式`）即可！

#### 组合 B3：硅基流动（免费 SenseVoice 整包听音）+ DeepSeek 大脑
- **第 1 步**：点「硅基流动」填 `sk-...` → 点「🚀 一键设为当前主力方案」。
- **第 2 步**：点「DeepSeek」填 `sk-...` → 点「🧠 一键设为文本大脑（二阶段润色 & 军师）」。
- **核对「2. 工作流与模型自由混搭」**：
  - `👂 听音转写引擎`：高亮 **硅基流动**，模型 `FunAudioLLM/SenseVoiceSmall`（`HTTP` 整包上传）。
  - `🧠 二阶段语义润色 & 写作快译模型`：高亮 **DeepSeek**，模型 `deepseek-chat`。

### ⚡ 实用提速技巧：流式口述直出 vs 二阶段 DeepSeek 润色怎么取舍？
在 **「2. 工作流与模型自由混搭 -> 🧠 二阶段语义润色 & 写作快译模型」** 卡片右上角有一个开关：
- **打开开关（默认）**：每次按麦克风说完话，都会先过一遍 `deepseek-chat`（自动关思考，约 `0.4~0.8s`）帮你去口癖、补标点、按当前 App 调语气。
- **关闭开关（追求 0.3s 极速直出）**：如果你用 **豆包 SeedASR 2.0** 或 **百炼千问流式** 识别本身已经很准，可以把这个开关**关掉**——此时日常语音输入**松手 0.3s 秒出**不再等二阶段，而 **`✍️ 帮写`、`🔍 问AI` 和 `✦ Jev 军师` 依然会自动调用你的 DeepSeek！**

## 五、军师思考模式与流式上屏最佳设定

### 1. DeepSeek 跑 `✦ 军师` 应该选 `deepseek-chat` 还是 `deepseek-reasoner`？
- **推荐直接选 `deepseek-chat`，并让「思考模式」保持 `自动 (AUTO)`**。
- 新版在军师场景下，会自动给 `deepseek-chat` 注入 `"thinking": {"type": "enabled"}` 并启用 **SSE 全链路流式上屏**：
  - 既保留完整潜台词深度推演；
  - 又能在推理完思考链后立刻先刷出 **潜台词雷达**，随后 **逐张点亮并可提前点击 3 张策略卡**，大幅减少白屏干等。
  - 同时，当你在日常输入里复用 DeepSeek 做口语润色时，系统仍会自动关闭思考，保证打字不卡顿。
- 如果你想对军师单独指定更强或带视觉能力的模型，开启 **「✦ Jev 军师专用模型」** 即可（例如平时润色用 `deepseek-chat`，军师专用挂 `doubao-seed-2-1-pro-260915` 或 `qwen-vl-max-latest` 来识图看表情包）。

### 2. DeepSeek 军师需要开「附带聊天截图」吗？
- DeepSeek 官方接口为纯文本架构，新版在军师路由器至 `deepseek-chat`（且未配置 Gemini 视觉兜底）时，会**自动跳过无意义的 720p 截屏与本地 OCR**，直接基于无障碍抓取的聊天上下文秒发起请求。
- 若你开启了 **豆包 `doubao-seed-2-1-pro-260915`**、**百炼 `qwen-vl-max-latest`**、**硅基 `Qwen2.5-VL-72B`** 或 **Gemini** 作为军师，且遇到了微信/QQ 等复杂自绘界面或需要看表情包，可保持截图开启以获得多模态视觉辅助。

## 六、常见配置排查（FAQ）

1. **语音录入提示：「语音听写（一阶段 STT）尚未配置 API Key…」**
   - 说明你只配了 DeepSeek，还没有给一阶段配任何听音引擎（或当前一阶段还停留在未填 Key 的默认通道）。
   - **解决**：按第四章任意 B1 / B2 / B3 组合，在保险箱填好百炼、豆包或硅基流动的 Key 并在 `👂 听音转写引擎` 中点选它即可。
2. **用硅基流动时报错 HTTP 404 或提示模型不存在**
   - 检查是否误把 `deepseek-chat` 填到了「👂 听音转写引擎」里，或反之把 `SenseVoiceSmall` 填到了二阶段里。
   - **听音**必须是 `FunAudioLLM/SenseVoiceSmall` 等语音模型；**二阶段**必须是 `Qwen/...` 或 `deepseek-ai/...` 文本模型。
3. **豆包流式连接报错 / 鉴权失败（`X-Api-Key` / `401`）**
   - 核对第 2 栏填的是 **豆包语音控制台** 的 Token（而非只开了方舟文本的 Key），以及确认在豆包语音控制台是否已经正式**购买或领取了「流式语音识别大模型」免费额度**（对应 `volc.seedasr.sauc.duration`）。
4. **如何自己验证接口通不通、快不快？**
   - 在任意模型输入框右侧点击 **「获取并测速（⚡）」**，TypeFree 会实时拉取当前渠道可用模型并测出每款模型的真实首字延迟（`ms`），看到绿色的毫秒数即代表网络与 Key 均完全打通。
