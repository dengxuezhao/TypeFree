| :--- | :--- |

## 二、初始启用与 API 工作台配置

### 2.1 三步启用输入法

1. 打开 TypeFree 主应用，在 **首页** 顶部引导卡片依次完成：
   - **启用输入法**：在系统「语言与输入法」中勾选 `TypeFree`。
   - **切换输入法**：将当前默认输入法设为 `TypeFree`。
   - **开启无障碍服务（可选）**：仅在使用 **全局悬浮语音胶囊** 或 **✦ Jev 军师读屏上下文** 时需要；纯打字与基础语音输入无需此权限。

### 2.2 三层统一接口工作台（`语音与 AI → 模型与 API`）

TypeFree 全面采用 **BYOK（Bring Your Own Key）** 架构，零中间服务器、零订阅费：

- **第 1 层 · 厂商凭证保险箱（Provider Vault）**
  - 支持 Google Gemini、DeepSeek、阿里云百炼、火山引擎（豆包）、硅基流动与自定义 OpenAI 兼容网关。
  - 各家 API Key 独立加密保存在本机 `EncryptedSharedPreferences`，切换方案时不会覆盖或丢失已保存凭证。
- **第 2 层 · 一键推荐组合预设**
  - 填入对应 Key 后可直接点选推荐组合（例如 Google Gemini Live 极速流式、DeepSeek 单 Key 全链路、国内百炼/豆包双阶段极速）。
  - 国内直连与混搭细则见 [国内直连 API 与 DeepSeek 混搭配置指南](domestic-api-setup-guide.md)。
- **第 3 层 · 精细模型路由与 `1-Token` 实测测速**
  - 可分别指定 **语音识别（STT）**、**文本润色与创作（LLM）**、**多模态音频直出** 与 **Jev 军师专用模型**。
  - 模型列表内置 **⚡ 测速**，并发实测当前凭证下各模型首字延迟（ms）并按速度排序。
  - 支持按模型配置 **思考模式（Thinking）**：日常听写建议关闭思考以获得最低延迟，军师分析可自动采用有界精炼思考。

### 2.3 DeepSeek 单 Key 全链路支持

在「厂商凭证保险箱」填入官方 DeepSeek API Key 后，支持两种用法自由切换：

- **单 Key 全链路闭环**：一阶段语音识别直连官方 `POST https://api.deepseek.com/v1/tools/asr`（上传 16kHz 单声道 WAV，服务端自动识别中/粤/英/日/韩），二阶段润色、帮写、问 AI 与军师统一调用 `deepseek-chat`。
- **双阶段混搭**：仅将 DeepSeek 用作二阶段文本大脑，一阶段保留阿里云百炼 / 豆包实时流式听音以获得边说边出字体验。

## 三、AI 语音输入与全局悬浮胶囊

### 3.1 语音面板基础交互

- **单击麦克风**：开始录音，再次点击结束识别并润色上屏。
- **长按麦克风**：按住说话，松手即刻完成识别与上屏。
- **录音取消**：录音过程中点击左侧 `✕` 立即丢弃本次内容。
- **自动口语净写**：自动剔除“嗯、啊、那个、然后”等口癖，识别句中改口（如“明天三点，不对，四点开会”自动整理为“明天四点开会”）并智能加标点。
- **超长语音无感续接**：单次超过 60 秒的长语音在静音边界自动轮换会话并分段并发润色。

### 3.2 流式边说边写（`实时写入输入框`）

- 位置：`语音与 AI → 语音与热词 → 实时写入输入框`（或键盘顶栏左侧 `⊞ → 实时写入`）。
- 工作方式：说话期间识别草稿以组合态（Composing Text）实时写入宿主输入框，松手后原地替换为润色定稿，同时顶栏给出 **↶ 撤回** 按钮。
- 冲突防护：针对 QQ 等存在异步选区回调的编辑器内置幂等去重；若录音期间用户手动移动光标，流式写入会自动冻结组合态，避免误覆盖其他文字。

### 3.3 语音体验增强项

- **轻声高灵敏收音（Whisper Mode）**：在夜间或安静环境贴近麦克风低声说话时，对 16-bit PCM 执行软限幅增益放大，语音面板也可一键临时切换。
- **录音时自动暂停外放媒体**：按下麦克风瞬间暂停当前音乐/视频外放，结束录音后自动恢复。
- **光标上文语境感知**：自动读取光标前最多 80 字作为语境提示，提升标点衔接与人称代词连贯性。
- **打字改错热词自学习（Myers Diff）**：语音上屏后 60 秒内若手动修正了专有名词，端侧自动比对差异并将正确写法沉淀为个人词典热词，下次语音识别优先命中。

### 3.4 全局悬浮语音胶囊（免切键盘）

- 位置：`语音与 AI → 语音与热词 → 启用悬浮语音胶囊`（需开启无障碍服务）。
- 在任意 App 输入框聚焦时静默浮现，支持单击免提、长按说话与选中文字后直接语音改写；在 Android 13+ 优先走原生光标级无污染直插。
- 密码框、支付与银行等敏感界面自动隐身避让。

## 四、AI 创作与社交辅助工作台

### 4.1 ✦ Jev 军师（读屏上下文 + 五层决策树）

点击键盘顶栏 **✦ 军师** 触发，专门负责社交/职场/群聊回复决策（完整白皮书见 [Jev 军师五层决策树](jev-decision-tree.md)）：

- **按需读屏与端侧脱敏**：仅在用户手动点击时读取当前可见聊天视口，自动裁除状态栏与键盘；手机号、身份证号、银行卡号、微信号等在端侧先替换为 `[手机号_1]` 占位符再发送至模型，回复上屏前本地无损还原。
- **可选附带脱敏截图**：开启 `语音与 AI → AI 与风格 → 读屏允许附带脱敏截图` 后，可识别微信/QQ 自绘气泡、截图与表情包；关闭则仅传纯文本。
- **五层正交分析与多策略草稿**：区分 1v1 私聊、群聊当事人与群聊旁观者；遇到技术/知识讨论自动启动事实筛子与内行平视三轴（同频升维 / 温和勘误 / 极客外推），遇到人情沟通输出潜台词分析与多张可直接点选的回复草稿。
- **按住说底牌**：可在军师面板按住补充你的真实诉求或底线，即时重算回复策略。
- **Jev 关系记忆**：开启后以设备本地 HMAC-SHA256 匿名锚点记录对象身份与偏好语体，不保存明文姓名或聊天记录。

### 4.2 ✍️ 纯净帮写（零读屏创作台）

点击键盘顶栏 **帮写** 触发，全程 **零读屏、零截屏**：

- **空输入框**：直接呈现常用体裁芯片（种草安利、朋友圈文案、工作周报、请假通知、催办跟进、致谢祝福、润色扩写），点选后可按住语音补充细节或直接生成。
- **已有草稿碎词**：无需手动全选，直接点击 `扩成种草文 / 润色得体 / 精简干练 / 扩写丰富 / 整理要点` 或口述要求即可一键成文。

### 4.3 🔍 顶栏「问 AI」随手查

- 位置：`语音与 AI → AI 与风格 → 顶栏「问AI」随手查胶囊`。
- 在普通输入框输入满 2 个字后，键盘顶栏自动浮现 **🔍 问AI** 胶囊。
- 点击后答案在 **键盘内部解答卡片** 中流式呈现，不会误发到聊天窗口；阅后可点 **「知道了（清空输入框）」** 无痕退回（支持一键恢复原问题），或点 **「填入输入框」** 引用发送。

### 4.4 🪄 选中文本改写 & 🌐 实时快译

- **选中改写**：在输入框选中一段文字后，键盘顶栏浮现 **AI 改写**，可点快捷指令或语音口述修改意见，支持一键撤回。
- **实时快译**：支持键盘内快译面板与语音麦克风长按上滑弧形语种轮盘直译上屏。

### 4.5 文风管理与 App 感知绑定

- 在 `语音与 AI → AI 与风格` 中可自定义多套润色文风，并为不同宿主应用（如微信、飞书、邮件、终端）绑定默认文风，切换应用自动生效。

## 五、原生 librime 全键盘与多方案码表系统

TypeFree 内置原生编译的 **C++ `librime 1.17.0`**（含 `librime-lua`、`librime-octagram`、`librime-predict`），提供完整的离线中文打字体验。

### 5.1 内置与一键预设方案

| 方案类型 | 方案名称 | 说明 |
| :--- | :--- | :--- |
| 内置开箱即用 | **全拼（雾凇拼音 `rime_ice`）** | 整句拼音、简拼、动态调频、支持一键 SHA-256 校验下载 58 万完整词库 |
| 内置开箱即用 | **小鹤双拼（整句）** | `double_pinyin_flypy` 整句双拼与自由联想 |
| 内置开箱即用 | **小鹤音形（四码顶功）** | 四码定长顶功；公开标准版内置基础开源词表，支持用户自行导入官方/自制 Rime 码表包 |
| 词库页一键预设 | **星空键道 6（`xkjd6`）** | 开源顶功音形方案，内置 `librime-lua` `topup_processor` 原生顶屏 |
| 词库页一键预设 | **五笔 86（`wubi86`）** | 经典四码定长纯形码表，空码不乱切分，第 5 码自动顶首选上屏 |
| 自定义导入 | **任意 Rime `.zip` / `.yaml` / `.tsv` 方案** | 支持同时安装多套自定义方案并在「方案与布局」卡片内自由切换 |

> **多方案自动原型识别与功能隔离**：导入自定义方案时，`SchemaInspector` 会自动识别方案原型（音形定长 / 顶功码表 / 纯形定长 / 整句拼音），并严格隔离各项增强开关——非小鹤音形方案不会触发小鹤 `o*` 指令或误拦截字母码，避免跨方案干扰。

### 5.2 码表零干扰增强体系（`键盘 → 方案与布局`）

- **纯正四码定长与零干扰直通**：不强行篡改原生码表排序；四码输入中遇完整码位不因英文前缀被误切或吞码；组合态按回车直出原始英文编码（不再附带多余换行）。
- **单字模式（`odz` 或面板开关）**：开启后候选严格过滤为单字（含 UTF-8 四字节 CJK Ext B~I 生僻字完整计数支持），方便精准录入人名或古籍用字。
- **候选「`,` / `.`」选二三选**：有候选时底排逗号选第 2 候选、句号选第 3 候选；关闭则回归常规标点顶字。
- **2D 展开候选网格 & 长按候选操作**：点击候选栏右侧展开按钮可进入多列候选大网格；长按任意候选词支持 **置顶调序** 或 **删除自造词**。
- **自然延续（BriefPrefixIndex v3）与逆向切码**：针对简码与全码关系提供不打断连打节奏的延续候选与切码提示，支持按需单独开关。
- **L1 + L2 本地造词体系**：
  - **L1 显式造词**：在 `键盘 → 词库管理` 中手动录入新词，支持小鹤音形自动推码与手动微调。
  - **L2 重复打字建议造词**：当同一新词组被连续重复打出多次时，预测栏弹出一次性确认芯片（自动过滤叠词与已有词条），点击 **加入** 即刻以 `0ms` 生效，点 `✕` 可直接忽略不再打扰。

### 5.3 小鹤音形 `o*` 快捷指令速查（仅小鹤音形生效）

可在 `键盘 → 方案与布局 → 小鹤 o* 快捷指令` 开关：

| 编码 | 作用 | 说明 |
| :--- | :--- | :--- |
| `orq` | 日期与星期 | 直出多种格式日期/星期，支持按天前后偏移 |
| `ouj` | 当前时间 | 直出当前时分/完整时间戳 |
| `ofi` | 反查编码 | 反查最近上屏或剪贴板中汉字的小鹤拆分编码 |
| `oqm` | 全码字模式切换 | 切换是否显示/启用全码字提示 |
| `odz` | 单字模式切换 | 一键开启/关闭单字过滤模式 |
| `ovy` | 语音切换 / 辅助指令 | 快速触发内置直通功能 |
| `ojf` | 简繁转换切换 | 即时切换简体 / 繁体输出 |
| `oai` | 标点模式切换 | 切换中英文标点输出状态 |

## 六、26 键三向手势、键帽角标与编码短语

### 6.1 每键三向操作（点击 / 上滑 / 长按）

### 6.2 键帽角标三档显示模式

位置：`键盘 → 方案与布局 → 通用打字键盘 → 键帽角标显示` 或 `键盘 → 手势与短语 → 键盘键帽顶部角标`：

- **上滑角标（默认）**：在键帽顶部居中显示上滑动作的紧凑单字形角标，与高字母（`t/i/f/b/h/k/l`）零碰撞。
- **长按角标**：在键帽顶部居中显示数字/长按副符号，适合习惯数字上标视觉参考的用户；实际触发上滑时气泡预览仍准确提示上滑符号。
- **隐藏角标**：切换为极简纯字母键帽，主字母自动恢复垂直正中对齐（`0dp` 偏移），所有上滑与长按手势仍完整生效。

### 6.3 上滑句号 `/` 引导编码短语 & 语音口令

- 位置：`键盘 → 手势与短语`。
- **打字触发**：在 26 键底排 **上滑句号键（`.` / `。`）** 输出 `/` 引导符，随后输入自定义短码（例如 `/dz`、`/yx`、`/sd`）即可在候选栏 `0ms` 展开预设长文本（邮箱、收货地址、常用模板等）。
- **语音触发**：为同一条短语绑定语音口令词后，语音模式说出该口令同样 `0ms` 本地直出，无需等待云端模型。

### 6.4 四码 5 键底排

- 位置：`键盘 → 方案与布局 → 四码 5 键底排（宽次选 ,）`。
- 开启后底排精简为 **`123 · ，（宽次选） · 空格（长按切中英） · 。（三选） · 回车`**，显著扩大次选逗号热区并降低误触句号概率。

## 七、打字效率辅助与智能剪贴板 2.0

### 7.1 输入框算式自动提示（被动计算器）

- 位置：`键盘 → 方案与布局 → 输入框算式自动提示`。
- 在任意输入框敲入合法算式（如 `125*8=`、`(35+15)*2`、`金额（12×3）÷4=`），预测栏自动浮现计算结果芯片，点击即刻补全。
- 支持空白边界隔离（如先算出 `123*8=984` 后空一格继续打 `1*1`，仅计算当前新算式 `1`，不会串算前文数字），自动忽略 `a=50`、`v1+2` 等非算式文本。

### 7.2 英文模式词库联想

- 位置：`键盘 → 方案与布局 → EN 英文模式词库联想`。
- 切换至英文模式并输入 `≥2` 个字母时，预测栏基于本地轻量前缀树实时提供常用英文单词补全，纯离线零延迟。

### 7.3 智能剪贴板 2.0（最多 200 条）与大爆炸拆词

- 位置：`通用 → 剪贴板设置` 与键盘顶栏剪贴板图标 / `⊞ → 剪贴板`。
- **顶栏双胶囊粘贴**：复制含验证码或取件码的短信后，顶栏同时弹出左胶囊（仅提取的纯验证码/取件码）与右胶囊（完整全文），按需一键填入。
- **多实体自动识别**：自动解析菜鸟货架码（如 `3-2-1048`）、丰巢取件码、主流快递单号（SF/JD/YT/JT 等）、手机号、验证码、网址、邮箱与收货地址；单条含多实体时并排给出独立芯片。
- **💥 大爆炸拆词**：点击剪贴板卡片右上角「拆词」，可在键盘内将长文本切分为独立词块自由多选、去标点并组合粘贴。
- **自动隐私过滤**：自动识别并跳过密码管理器等敏感来源剪贴内容，最多保留最近 200 条未置顶记录（置顶条目不受淘汰影响）。

### 7.4 `⊞` 4×2 快捷工具面板

点击键盘顶栏最左侧 **`⊞`** 可在不跳出宿主 App 的前提下原位展开 8 项高频快捷操作：
- 第一行：**剪贴板** · **键盘高度** · **输入方案** · **文风**
- 第二行：**AI 补全** · **实时写入** · **词库** · **设置**

## 八、键盘外观、人体工学与大字体适配

- **高度双模调节**：
  - **等比缩放模式（STRETCH）**：5 档键盘总高调节，紧凑档释放更多聊天可视区。
  - **底部垫高模式（LIFT）**：保持标准键帽黄金比例不变，在键盘底部增加 `0dp / 8dp / 16dp / 24dp / 32dp` 五档留白垫高，解决全面屏底部手势条顶手与大屏拇指下探疲劳。
- **可选顶部数字行与按下气泡放大**：均可在 `键盘 → 方案与布局 → 通用打字键盘` 独立开关。
- **系统大字体防扭曲保护**：
  - IME 键盘根节点独立锁定 `fontScale = 1.0f`，手机系统调至极大字号时键帽、角标与顶栏依旧工整不错位。
  - 主应用界面将 `fontScale` 合理钳制在 `0.85x ~ 1.15x`（26 键迷你预览锁定 `1.0x`），兼顾可读性与布局完整。
- **三套主题**：浅色单色、深色曜石、跟随系统自动切换。

## 九、隐私安全、备份迁移与常见问题

### 9.1 隐私与安全边界

1. **零中心服务器**：无官方云端中转、无统计埋点、无广告 SDK。
2. **数据直连你自己的端点**：语音与 AI 请求仅发往你在「模型与 API」配置的官方或自建服务。
3. **无痕模式（Incognito Mode）**：在密码框、声明 `IME_FLAG_NO_PERSONALIZED_LEARNING` 的隐私输入框或手动开启无痕模式时，暂停一切个人词频记录、Rime 用户词典写入、剪贴板监听与历史保存。
4. **敏感界面强制熔断**：银行、支付、密码管理器与密码框强制禁用悬浮球、读屏上下文与 AI 补全。

### 9.2 配置备份与换机迁移

- 在 `通用 → 配置备份与恢复` 中可导出完整 JSON 配置（包含输入方案、26 键自定义手势、键帽角标模式、短语、文风与模型路由，API Key 默认自动脱敏保护，可按需选择）。
- 导入备份时采用安全白名单字段合并，旧版本备份可直接向上兼容迁移。

### 9.3 公开标准版与小鹤专享版区别

- **公开标准版（`standard`）**：托管于 GitHub Releases，遵循 GPL-3.0 协议，仅内置开源词表（雾凇拼音、小鹤双拼、基础开源小鹤词表、一键预设五笔 86 / 星空键道 6），并支持用户在「词库管理」中自由导入自己的私有 Rime 方案包。
- **小鹤音形专享版（`xiaohe`）**：因小鹤官方私有码表受 EULA 协议约束，私有词表资产严格隔离于公开代码仓库之外，仅通过专属渠道离线打包分发；公开标准版直接覆盖安装会替换内置私有词库，请按对应渠道更新。
