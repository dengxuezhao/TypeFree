- 新增拼音/双拼候选栏与上屏后 Emoji 联想提示、Emoji 面板扩充至 827 个主流表情、重构悬浮语音胶囊直出体验并修复三星 One UI 底部留白/透字问题

#### ✨ 新特性

- **拼音 / 双拼 Emoji 智能提示（拼写中 + 上屏后双入口）**：在全拼、九键拼音及全部 6 种双拼的中文输入模式下，拼写短词时自动在第 2 候选后提示匹配 Emoji（不影响空格选一选、分号选二选，也不干扰 Rime 分步选词）；上屏后在联想栏前 2 个续词后提供 1~3 个高置信 Emoji，支持去语气词（如「笑死了」「收到啦」）、2~4 字尾词匹配（如「今天太开心了」）、繁简体通用、否定前缀防误触以及连点连发（如 `😂😂😂`）。形码（小鹤音形四码）与自定义 Rime 方案、密码/网址/邮箱框保持零打扰。
- **827 个主流表情面板 + 7,682 条简繁中文词表**：Emoji 面板由 187 个扩充至 **827 个**主流表情，新增 `✈️ 旅行` 分类，修复复合人物表情肤色拼接与非标准单肤色项，按本机字体自动过滤缺字；内置基于 Unicode CLDR `zh` / `zh-Hant` 与日常高频聊天词构建的 7,682 条纯离线中文映射词表。
- **悬浮语音胶囊开箱直出与全链路加固**：在微信、QQ、飞书、钉钉、Telegram 等聊天页无需先点输入框再收起键盘即可自动弹出胶囊；无障碍扫描全面迁至独立后台线程并采用「先非列表、延后 RecyclerView」两阶段策略，杜绝大群列表卡顿；拆离聚焦/推断语义不向云端上传未聚焦输入框文本，录音开始锁定目标指纹防止切页误写，整页可见密码框自动屏蔽，未聚焦写入不弹起软键盘。
- **按键音效支持 0% 静音**：通用设置中的按键音效音量调节下限由 `5%` 调整为 `0%`（完全静音），可独立保留震动反馈同时关闭按键声音。

#### 🛠️ 问题修复

- **修复三星 One UI（Android 16）等机型 0 垫高留白与底部导航栏透字问题**：改为按 `decorView` 与输入法实际视图的重叠高度动态扣减系统已预留空间，并为预留底栏同步键盘画布底色与不透明背景垫片，彻底消除底部双倍灰边与底层页面文字透出，同时保留 OriginOS 7、MagicOS 11 等系统底部防遮挡保护。
- **修复横竖屏切换或隐藏底栏后安全边距滞留并增强零隐私诊断快照**：统一收口窗口 inset 与布局监听，并在「关于 → 运行诊断快照」补充窗口几何与底栏像素读数（不含任何输入或聊天文字），便于跨机型定位问题。
